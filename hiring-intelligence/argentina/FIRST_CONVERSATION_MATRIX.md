# Matriz de la primera conversación

Se completa **inmediatamente después** de cada conversación, con frases textuales cuando sea posible. Una conversación es **una observación**, no una prueba. Las decisiones finales se toman con `GO_NO_GO.md`, después de al menos 3 conversaciones.

| # | Qué averiguamos | Respuesta (textual o resumida) | Qué indica | Decisión provisional |
|---|---|---|---|---|
| 1 | ¿Les faltan clientes o les sobra demanda? | | Faltan → hay dolor de adquisición. Sobra → el problema es otro | Si sobra: pasar a la fila 7 |
| 2 | ¿Cómo llegaron sus últimos 3 clientes? | | Mayoría por referidos o red → la prospección pesa poco | Anotar canales |
| 3 | Tarea comercial que más tiempo les consume | | ¿Coincide con investigar o detectar empresas? | Sí → seguir con la hipótesis. No → anotar cuál es |
| 4 | Horas por semana y quién la hace | | Más de 3 h/semana = costo relevante | Menos de 1 h → dolor bajo |
| 5 | Herramientas y gasto actual (incl. ChatGPT o LinkedIn) | | Con eso les alcanza → poca diferenciación posible | "Les falta X" → anotar X |
| 6 | Valor de un cliente nuevo (fee, procesos al año) | | Techo de lo que podrían pagar | Si es bajo → precio inviable |
| 7 | **Otro problema costoso y repetitivo que mencionaron por su cuenta** | | Candidata a oportunidad nueva para resolver con IA | Si aparece en 2 o más conversaciones → evaluarla |
| 8 | ¿Tercerizan algo hoy? ¿Qué y cuánto pagan? | | Muestra disposición real a pagar por servicios | Anotar el precio de referencia |
| 9 | Respuesta al cierre ("¿qué tendría que cumplir…?" / "¿puedo volver a escribirles?") | | Señal de compra solo si hay un próximo paso concreto | Pide presupuesto → preparar propuesta mínima |
| 10 | Objeciones o motivos para no contratar | | | |

**Resultado de esta conversación** (marcar una):
- [ ] Confirma un problema de adquisición costoso que no resuelven bien con lo que usan.
- [ ] Confirma el problema, pero lo resuelven bien con sus herramientas o con ChatGPT.
- [ ] No tienen problema de adquisición; mencionan otro problema: ______
- [ ] Sin información útil (conversación demasiado corta o desviada).

**Próxima acción** (una sola): ______

> Recordatorio: tres conversaciones son una señal direccional, no estadística. Si las agencias no necesitan investigación comercial, se reconoce enseguida y se explora el problema que sí mencionen (fila 7).
